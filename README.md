# Architecture Patterns

Guidance for selecting and applying software architecture patterns to system design problems.

## Features

- Focused workflows and domain-specific guidance.
- Practical examples and implementation recommendations.
- Best practices and validation considerations.

## Installation

Copy the skill into your agent skills directory:

```bash
mkdir -p .claude/skills/architecture-patterns
cp SKILL.md .claude/skills/architecture-patterns/SKILL.md
```

## Usage

Ask your AI coding assistant to use **Architecture Patterns** when working on a related task. Follow the instructions in `SKILL.md`.
